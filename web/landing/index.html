BEFORE YOU DROP IN

GOOD TO KNOW.

Is this the original Combat Arms client?

DeCombat is a new, independent emulator for the 2009 Combat Arms EU client folder. Its own Rust code handles the client and servers; it never runs the original executable or libraries.

Where do I get the original game files?

You must supply a legitimate copy of the supported 2009 EU client yourself. This site and the DeCombat packages do not distribute the original game files.

How are mods approved and verified?

The community directory records reviewed mod IDs, versions and package hashes. A verified badge is an exact match to that record, not a guarantee for every version of a mod. Other packages require explicit consent in the client. Vanilla servers load no mods.

Can I play on a Mac or iPad?

Apple Silicon Mac builds are playable. Intel Mac builds exist but hardware validation is pending. The experimental iPadOS port has been play-tested on an M4 iPad Pro with a Bluetooth keyboard and mouse; installation currently requires Xcode. There is no App Store release.

Is DeCombat affiliated with Nexon or Valofe?

No. DeCombat is an independent community project, not affiliated with, endorsed by or sponsored by Nexon, Valofe, or the owners of the original game and technology.

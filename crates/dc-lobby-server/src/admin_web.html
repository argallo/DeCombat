Add a security key

Only a YubiKey with a PIN is accepted. This link works once.

  1. Type a name for the key, then click outside the box. A YubiKey touched while a text box has the cursor types a code into it.
  2. Press the button and choose "Security key" if the browser asks.
  3. Allow the browser to show the key's make and model: that is how the server knows it is a YubiKey.
  4. Enter the key's PIN and touch it.
